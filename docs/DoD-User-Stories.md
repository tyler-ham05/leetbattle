# Definition of Done – User Stories

A user story is done only when **every** item below is checked. This checklist applies to every user story. Each story's own acceptance criteria are in its sprint plan (e.g. `docs/sprint4/sprint-4-plan.md`).

- [ ] Code is written and peer-reviewed
- [ ] All acceptance criteria for the story are satisfied
- [ ] Unit and integration tests are written and passed
- [ ] No high-priority open defects remain
- [ ] Code is merged and deployed to the staging/test environment
- [ ] User or help documentation is updated
- [ ] Product Owner has formally reviewed and signed off
