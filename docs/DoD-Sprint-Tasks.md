# Definition of Done – Sprint Tasks

A sprint task is done only when **every** item below is checked. This checklist applies to every task. Each task's own acceptance criteria are in its spec under `docs/tasks/`.

- [ ] Spec is committed and all acceptance criteria are met
- [ ] Code is checked into the repository
- [ ] Code passes linting
- [ ] Code passes copy-paste detection with up to 5% duplication
- [ ] Code runs and passes all test suites
- [ ] Any necessary documentation is updated/written
- [ ] Code has been peer-reviewed and is ready to merge

The linting, duplication and test coverage rules are described in [Coding Standards](CodingStandards.md).
