# Teammate presence in the workspace switcher

## Description
Serves US-6 (In-Game, #67). In a match, each teammate's tab in the workspace switcher shows which question they are working on, so the team can split the work without asking in chat.

## Specs
- The game socket keeps, for each teammate, the question id of their most recent `game:code` update (and the latest entry per teammate from `game:code:snapshot`).
- Each teammate's tab in the workspace switcher shows "Q<n>" after their name in muted text (n = the question's 1-based position in the pool). It shows nothing until that teammate has edited anything.
- Opening a teammate's workspace opens it on that question.
- The disconnected icon and fading stay as they are.

## Requirements
- No new dependencies and no backend changes.
- Use only the theme classes defined in docs/frontend/theming.md. No dots or badges.
- Frontend tests (`frontend/test/`) do not touch backend services.

## Acceptance criteria
1. A teammate who edits question 2 shows "Q2" on their tab.
2. A teammate who hasn't edited anything shows no question.
3. Opening that teammate's workspace shows question 2.
