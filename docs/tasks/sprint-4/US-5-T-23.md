# Editor: see your output, clear verdicts, resizable panes, shortcuts, question status

## Description
Serves US-5 (UI/UX, #74). The practice and match editor shows what your code returned, makes Accepted and failures easy to tell apart, lets players resize the panes, adds the usual Run and Submit shortcuts, and marks which questions you've solved.

## Specs
- Test cases panel: after Run, the selected case shows "Your output" under Expected output, and the case tabs show each case's result by text color only (primary for passed, danger for failed, no icons or dots).
- Results panel: the verdict is primary when Accepted and danger otherwise. Passed, Input, Expected and Your output are laid out in the same label + `bg-raised` mono block style as the test cases panel.
- Copy: "Expected Output" becomes "Expected output", and "No test cases available for this problem." loses its period.
- The question/code split and the code/test cases split can be dragged to resize them (each pane at least 20%), and also with the arrow keys on a focused divider, which has `role="separator"`.
- Ctrl/Cmd+Enter runs the code, and Ctrl/Cmd+Shift+Enter submits it. Neither works in someone else's read-only workspace or while a run or submit is already going.
- Question navigation (1 / 2 / 3): a question you've had Accepted shows its number in the primary color. One you submitted but haven't solved shows it in muted color with an underline. No badges, ticks or dots.
- Question panel: difficulty colors use the theme tokens (primary / secondary / danger, see theming.md) instead of hardcoded green, yellow and red. The commented-out tags code is removed, and "Loading question..." uses "…".

## Requirements
- No new dependencies.
- Use only the theme classes defined in docs/frontend/theming.md. No decorative dots.
- Frontend tests (`frontend/test/`) do not touch backend services.

## Acceptance criteria
1. After Run, the selected case shows the player's output.
2. Accepted is primary and other verdicts are danger.
3. Both dividers resize their panes by mouse and by keyboard.
4. Ctrl/Cmd+Enter runs and Ctrl/Cmd+Shift+Enter submits.
5. Solved questions are marked in the question navigation.
6. Difficulty uses the theme colors.
