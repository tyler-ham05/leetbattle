# Match top bar scoreboard, visible score count-up, name in the top bar

## Description
Serves US-4 (Polished Match Experience, sprint 4). The match top bar reads like a scoreboard and the score visibly counts up when a team scores. The player's name replaces the three-line menu icon on every page, and leftover filler text is removed.

## Specs
- **Visible count-up:** when a team's score goes up, the top bar counts from the old score to the new one over 1.2 seconds (it was 0.6, too quick to notice).
- **Scoreboard top bar:** each team's score is big and heavy in the team's color, with the team name ("Your team" / "Rival team") small above it in the main font and the team's color. The two columns face each other around the clock. In a 1v1 the labels are just "You" / "Rival". The clock uses the main font with same-width digits.
- **Name in the top bar:** the three-line menu icon becomes the player's name (or email when there is no name) in the primary color, with a small down arrow. It opens the same menu, which no longer repeats the name at its top. Screen readers still hear "Account menu".
- **Home title screen:** no name above the LeetBattle title.
- **Match page:** no subtitle under "Match".

## Requirements
- No new dependencies and no backend changes.
- Use only the theme classes defined in docs/frontend/theming.md. No decorative dots.
- Frontend tests (`frontend/test/`) do not touch backend services.

## Acceptance criteria
1. A score change counts up visibly over about a second.
2. The top bar shows big team-colored scores with the team names small above them.
3. Every page's top bar shows the player's name instead of the three-line icon, and clicking it opens the menu.
4. The home title screen and match page show no extra name or subtitle.
