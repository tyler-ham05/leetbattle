# Add a pick questions screen

## Description
Serves US-6 (In-Game, #67). After banning questions, teams should be able to pick the questions theyre working on.

## Specs
- There should be 9 questions (6 easy, 3 medium) for teams of 3, (4 easy, 2 medium) for teams of 2
- In a 1v1, this screen should be skipped as the questions should be assigned directly (2 easy, 1 medium)

## Requirements
- After the ban screen, every player can select 3 questions to work on
- Players should not be able to select questions their teammates have selected
- If questions are not selected, assign the remaining questions in order
- A timer should occur roughly similar to the ban screen that pulls players into the match afterwards

## Scope
- frontend/app/game
- frontend/test
- service/GameService

## Acceptance criteria
- Users should be able to select questions from the screen. 
- Questions selected should carry over into the game
