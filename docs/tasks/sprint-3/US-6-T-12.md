# Show connected teammates next to the Forfeit button

## Description
Serves US-6 (In-Game, #67). During a match the top bar has a Forfeit button (US-6-T-2), and a team forfeits once every connected teammate confirms. Nothing near the button shows who those teammates are. This task lists the player's connected teammates by display name in the top bar, right next to the Forfeit button, so a player can see who is still in the match with them before forfeiting.

Out of scope: the match roster in the page body, the forfeit vote itself (how many votes are needed, or showing who has voted), the other team's players, and any change to GameService or the `game:state` payload.

## Specs
- The teammates are listed in the top bar (`HomeTopBar`'s `actions`, in `frontend/app/_home/components/topbar.tsx`), rendered by the game page `frontend/app/game/[gameId]/page.tsx`.
- The list has the accessible name "Teammates" (`role="list"`, `aria-label="Teammates"`) and one item per teammate, whose text is that teammate's `displayName`.
- A teammate is an entry in the last `game:state`'s `players` (from `useGameSocket` in `frontend/app/game/socket-context.tsx`) that:
  - has the same `team` as the signed-in user (`useAuth` from `frontend/app/login/context`),
  - is not the signed-in user, and
  - has `connected: true`.
- Players on the other team and disconnected teammates are not listed. When a teammate reconnects or disconnects, the next `game:state` updates the list.
- Teammates are listed in the order they appear in `players`.
- The list sits immediately to the left of the Forfeit button, both inside the top bar.
- The list is shown exactly when the Forfeit button is: while the game is `playing` and has not ended. It is not shown while waiting for players, while banning, or after `game:ended`.
- When the player has no connected teammates (for example, in a 1v1), the list is not shown.

## Requirements
- Frontend only. No change to GameService, to the `game:state` payload, or to `socket-context.tsx`.
- Read the players from the existing `useGameSocket` and the signed-in user from `useAuth`. Do not add a second socket client or a new request.
- Keep `HomeTopBar`'s existing `actions` prop. Do not add a game-specific prop to the shared top bar.
- Colours use the theme tokens from `docs/frontend/theming.md`; no hard-coded colours.
- No new runtime dependencies.
- Frontend tests mock the game socket and never call a real backend service.
- The existing US-6-T-2 forfeit tests in `frontend/test/game.test.tsx` keep passing unchanged.

## Acceptance criteria
1. During a match, the top bar's "Teammates" list shows the display name of each connected teammate.
2. The "Teammates" list does not include the signed-in player.
3. The "Teammates" list does not include players on the other team.
4. The "Teammates" list does not include a teammate who is disconnected.
5. The "Teammates" list sits to the left of the Forfeit button.
6. The "Teammates" list is not shown while waiting for players, while banning, or after the game has ended.
7. When the player has no connected teammates, the "Teammates" list is not shown.
