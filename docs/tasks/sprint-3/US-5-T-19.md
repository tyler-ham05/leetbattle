# Practice and match layout

## Description
Serves US-5 (UI/UX). The practice page drops the parts that only make sense in a match, shows only the first three test cases like LeetCode, and the match page uses the same full-page editor layout as practice, with the teammate tabs showing who is disconnected. Design: the "Practice and match layout" canvas.

## Specs
- Practice shows no team scores, no timer and no team chat.
- Practice and match show at most three test cases ("Case 1" to "Case 3"). When a problem has more, a muted "+N hidden, run on submit" sits at the right of the case tabs. Run only runs the visible cases; Submit still runs every case on CodeService.
- While playing, the match page has no "Match" heading and no team rosters; the editor fills the page under the top bar. Rosters still show while waiting, banning and picking.
- While playing, the top bar shows Team 1's score, the time left and Team 2's score in the middle, and Forfeit on the right.
- The workspace tabs ("You", then each teammate) run across the page under the top bar. A disconnected teammate's tab is faded with a crossed-out wifi icon and is read as "<name>, disconnected"; it can still be opened.
- Viewing a teammate shows "<name>'s code, read only" in the code tab bar instead of the separate banner.
- Lobby bug fix: in a 1v1, the empty team's button says "Switch to Team 1" (not "Other team is full") for a player on the other team. A full team's button says "Team full".

## Requirements
- The changes are in `frontend/app/editor/`, `frontend/app/game/`, `frontend/app/_home/components/topbar.tsx` and `frontend/app/lobby/page.tsx`.
- No new dependencies.
- Use only the theme classes defined in docs/frontend/theming.md.
- Frontend tests (`frontend/test/`) do not touch backend services.

## Acceptance criteria
1. The practice page shows no "Team 1", "Team 2", timer or team chat.
2. A problem with more than three test cases shows only three case tabs and the hidden count, and Run sends only those three.
3. While playing, the match page shows no "Match" heading or rosters, and the top bar shows both scores and the time.
4. A disconnected teammate's tab is faded, shows the wifi icon and is labelled disconnected.
5. Viewing a teammate shows "<name>'s code, read only" in the code tab bar.
6. In a 1v1 lobby, a player on Team 2 sees "Switch to Team 1" while Team 1 has an open seat.
